一、戰爭的世紀：東亞秩序的重組

從1894年到1975年，東亞幾乎沒有一個世代沒有經歷戰爭。這一連串戰爭不是偶然，而是舊秩序崩解、新秩序尚未形成的過程：

  • 第一階段（1894－1945）：日本取代中國成為區域霸權，並以帝國主義方式重組東亞。
  • 第二階段（1945－1989）：美蘇冷戰取代日本帝國，東亞被切割為對立陣營，三場熱戰（韓戰、越戰、兩岸對峙）都在這裡發生。
  • 第三階段（1989－）：經濟整合快速推進，但分斷與歷史問題並未隨冷戰結束而解決。

甲午戰爭的關鍵地位

《馬關條約》中清朝承認朝鮮獨立（即放棄宗主權）、割讓臺澎、賠款二億兩（約為日本四年財政收入）。
三重意義：① 以中國為中心的宗藩體系正式終結；② 東亞主導權由中國移向日本；③ 引發列強瓜分中國的狂潮（租借地與勢力範圍），並刺激了戊戌變法與革命運動。
日俄戰爭則是近代亞洲國家首次戰勝歐洲列強，鼓舞了中國、越南（東遊運動）、印度、土耳其的民族主義者——但同時也讓日本走上帝國主義道路，形成雙面效應。

三、中日戰爭與太平洋戰爭

  • 1937年七七（盧溝橋）事變，中日戰爭全面爆發；第二次國共合作成立；同年底南京大屠殺。
  • 中國以空間換取時間，政府西遷重慶，戰事陷入長期化。
  • 1940－41年日軍進駐法屬印度支那，提出「大東亞共榮圈」；1941年12月偷襲珍珠港，太平洋戰爭爆發。
  • 1943年開羅會議與《開羅宣言》：議定日本須歸還東北、臺灣、澎湖，並使朝鮮自由獨立。
  • 1945年8月，日本投降。

如何評價「大東亞共榮圈」？

口號：解放亞洲、驅逐歐美殖民者、共存共榮。
實際：以日本為核心的軍事佔領、資源掠奪、強制勞動、皇民化與軍票經濟。
複雜之處：日軍確實在短期內瓦解了英法荷在東南亞的殖民統治，部分當地民族主義者（如印尼的蘇卡諾）曾與之合作以求獨立；但佔領區的殘酷統治旋即使各地轉為抗日。
結論：它客觀上加速了歐洲殖民體系的崩潰，主觀上卻是另一套殖民。這種「後果與動機不一致」的現象，正是歷史判斷的難處，也是申論題常見的切入點。

四、戰後處置與分斷體制

地區戰後處置後果
朝鮮半島美蘇以北緯38度線分別受降1948年南北分別建國，1950年韓戰後分裂固化
中國接收臺灣；國共內戰（1946－49）1949年中共建政、國府遷臺，形成兩岸分治
越南胡志明發動八月革命宣布獨立，法國重返1946－54第一次印度支那戰爭，17度線分治
日本美軍佔領、民主化改革；1947年新憲法1951年《舊金山和約》恢復主權，納入美國陣營

《舊金山和約》（1951）留下的爭議

① 和約僅載明日本「放棄」臺灣、澎湖的一切權利，未指明移交對象；
② 因中國代表權爭議，海峽兩岸政權皆未受邀簽署；
③ 部分島嶼歸屬（如釣魚臺隨沖繩交由美國託管、1972年隨沖繩「歸還」日本）未釐清。
這些模糊成為日後臺灣國際地位爭議與領土爭端的法理根源。同時簽訂的《美日安保條約》則確立日本在冷戰中的位置。

「分斷體制」是理解戰後東亞的關鍵詞：朝鮮半島（南北韓）、中國（兩岸）、越南（南北越，1975年統一）——三個地方都因冷戰而被一分為二，至今只有越南完成統一。

五、冷戰下的東亞：三場熱戰

韓戰（1950－1953）

  • 北韓南侵 → 聯合國軍（以美軍為主）介入 → 中國「抗美援朝」參戰 → 1953年停戰（至今仍是停戰，不是終戰）。
  • 連鎖效應：美國第七艦隊協防臺灣，兩岸分治固定化；日本因美軍「特需」訂單經濟復甦，並加速簽訂《舊金山和約》重返國際社會；東亞冷戰結構全面成形。

越戰（1964－1975）

  • 延續抗法的民族獨立與統一戰爭，同時是美蘇中在東亞的代理人戰爭，具雙重性格。
  • 韓國、泰國、澳洲等派兵協助美國；1973年美軍撤出，1975年西貢陷落，1976年越南統一。
  • 戰後出現大規模船民難民潮（見第4章）。

兩岸對峙

  • 1954－55、1958年兩次臺海危機；長期軍事對峙與宣傳戰。
  • 1971年中華人民共和國取得聯合國中國代表權，1979年美中建交，臺灣國際空間緊縮。

六、各國的戰後發展

國家政治經濟
日本1947年新憲法（主權在民、象徵天皇制、第九條放棄戰爭）；1955年體制下自民黨長期執政特需景氣 → 高度經濟成長 → 1964東京奧運、1968年GNP世界第二 → 1990年代泡沫破裂
中國1949建政 → 大躍進（1958）→ 文化大革命（1966－76）→ 1978改革開放 → 1989六四計畫經濟 → 1978後市場化、2001加入WTO、成為「世界工廠」
韓國威權統治 → 1960四一九、1980光州事件 → 1987六月民主抗爭恢復直選出口導向工業化、財閥體制，「漢江奇蹟」，亞洲四小龍之一
越南1976統一；1979中越戰爭1986革新開放（Đổi Mới），社會主義定向市場經濟，2007加入WTO

東亞發展模式的共同點

日本、韓國、臺灣、新加坡大致循同一路徑：威權政府主導 ＋ 出口導向工業化 ＋ 高儲蓄高教育投資 ＋ 美國市場開放。先經濟成長，再民主轉型（韓國1987、臺灣1987解嚴）。
中國與越南則走了另一條路：經濟市場化，但維持共產黨一黨體制，政治不隨經濟開放而多元化。

七、區域統合

  • 1955 萬隆會議：亞非29國集會，周恩來以「求同存異」促成共識，通過萬隆十項原則（和平共處五原則係1954年中印協定提出，十項原則由其擴充而來），第三世界與不結盟運動興起。
  • 1967 東南亞國家協會（ASEAN）：成立時帶反共色彩，冷戰後吸納越南、寮國、柬埔寨、緬甸成為「東協十國」。
  • 1989 APEC（亞太經濟合作會議）：跨太平洋的經濟論壇。
  • 1997 東協加三（＋中日韓）：因亞洲金融風暴而啟動；2000年清邁倡議建立貨幣互換機制。
  • 其後發展出東亞高峰會、東協自由貿易區、RCEP等多層次的合作架構。

為什麼東亞的統合深度不及歐盟？

① 歷史記憶未和解——歐洲有德法和解為基礎，東亞的戰爭責任問題至今懸而未決。
② 政治體制差異過大——民主國家、威權國家、一黨體制並存，難以建立共同的政治機構。
③ 缺乏安全互信——領土爭議與軍備競賽持續，且各國安全多倚賴與美國的雙邊關係而非區域機制。
④ 發展階段落差大——從已開發國家到低度開發國家並存。

八、未解的問題：領土與歷史認識

領土與海域爭議

爭議地當事方要點
釣魚臺列嶼（尖閣諸島）日、中、臺1972年隨沖繩「歸還」日本；2012年日本「國有化」引發激烈對立；周邊可能蘊藏油氣
獨島（竹島）韓、日韓國實際控制；與殖民歷史記憶高度糾纏
南海諸島中、臺、越、菲、馬、汶2016年仲裁否定中國「九段線」歷史性權利主張，中國拒不接受
北方四島（南千島）日、俄二戰末期蘇聯佔領，日俄迄今未簽和約

歷史認識問題

  • 教科書爭議：日本部分教科書對侵略的記述方式，屢引發中韓抗議。
  • 慰安婦：1993年河野談話承認軍方介入；2015年日韓協議宣稱「最終且不可逆」解決，但在韓國國內爭議不斷，2018年實質擱置。
  • 靖國神社參拜：因合祀甲級戰犯，首相參拜被視為對侵略歷史的肯定。
  • 道歉與反省：1995年村山談話就殖民統治與侵略表達「痛切反省與道歉」，是重要的官方表態。

為什麼歷史問題這麼難解？

因為它不只是學術問題。歷史記憶與各國的民族認同、受害者的尊嚴、以及國內的政治動員緊密綁在一起：對受害國而言，承認歷史是對尊嚴的基本尊重；對加害國的部分輿論而言，持續道歉被視為自我否定。只要雙方社會沒有形成共識，任何官方協議都缺乏支撐而容易反覆。
這正是歷史教育的意義所在——不是為了記恨，而是為了讓下一代有能力理解彼此的記憶如何形成。

九、總結

本章核心論點

當代東亞呈現「經濟熱、政治冷」的格局：區域內貿易投資高度整合、人員與文化往來前所未有地頻繁；但分斷體制（南北韓、兩岸）、領土爭議與歷史認識問題依然存在，區域統合的深度遠不及歐盟。
從朝貢體制、到帝國主義、到冷戰陣營、到今日的經濟網絡——東亞的秩序已經重組過四次。下一套秩序會是什麼樣子，取決於這一代人如何處理尚未解決的那些問題。
