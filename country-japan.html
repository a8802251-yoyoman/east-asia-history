東亞各國　｜　跨章整合

日本

本頁把所有談到日本的內容彙整為一條完整脈絡。日本是東亞史中最特殊的案例：它大量引進中國制度，卻保留了最不中國的政治結構；它是近代化最成功的亞洲國家，也因此成為最大的侵略者。

一、日本的三個特殊性

① 權威不可轉移

天皇被視為天照大神後裔，萬世一系。因為無法取而代之，實權者只能另建一套機構於其下，形成長達千年的二元權威。

② 引進律令卻不要科舉

官位依蔭位制由貴族家格世襲。推動律令改革的正是既有貴族，他們不可能引進會剝奪自身特權的制度。

③ 海洋的距離

與大陸隔海相望，使日本既能選擇性學習，也能選擇性中斷（廢遣唐使、鎖國），且從未被中國直接統治。

二、律令國家的建立　（第1、3章）

  • 57年倭奴國王受東漢封「漢委奴國王」金印；239年邪馬臺國卑彌呼受曹魏封「親魏倭王」——早期即藉中國冊封取得統治正當性。
  • 593年聖德太子攝政：冠位十二階（603，以才能授官）、十七條憲法（604，以儒佛規範君臣）。
  • 607年小野妹子遣隋，國書自稱「日出處天子致書日沒處天子」，試圖對等。
  • 645年大化革新：公地公民、班田收授（仿唐均田）、租庸調、中央官制。
  • 663年白村江之戰：敗於唐羅聯軍 → 退出朝鮮半島、修築水城山城、更積極學唐自保。
  • 701年《大寶律令》：設二官八省，律令國家完成。
  • 710年平城京（奈良）、794年平安京——皆仿長安棋盤式規劃。

三、二元權威：天皇與將軍　（第1章）

時期實權者天皇的地位
律令國家（7－9世紀）天皇本人實質統治者
攝關政治（平安中期）藤原氏（外戚任攝政、關白）被架空
院政（11世紀末起）上皇（退位天皇，「治天之君」）天皇、上皇、攝關三方角力
鎌倉幕府（1185／1192）源賴朝，征夷大將軍；後為北条氏執權名義權威的來源
室町幕府（1336）足利氏同上；1467應仁之亂後進入戰國
江戶幕府（1603）德川氏，幕藩體制同上，幕府權力達到頂峰
明治維新（1868）王政復古，廢幕府重新成為實質權威中心

江戶幕府的統治技術：幕藩體制（將軍直轄領＋大名藩國）、參勤交代（大名隔年赴江戶、妻子留為人質，消耗其財力）、士農工商世襲身分制、寺請制度（人人須隸屬寺院，由寺院登錄戶口）。

四、社會組織與宗教　（第2章）

  • 身分制：士（武士）農工商，另有穢多、非人等賤民。身分世襲、不可流動——與中國可藉科舉流動的士人社會形成最鮮明對比。
  • 佛教：538／552年經百濟傳入，蘇我氏（崇佛）與物部氏（排佛）鬥爭後成為國家宗教（鎮護國家）。
  • 寺院勢力：中世寺院擁有莊園與僧兵，延曆寺、興福寺能左右朝政；一向一揆（淨土真宗信徒）可與大名對抗。
  • 納入統治：織田信長火燒比叡山；豐臣、德川推行寺請制度——宗教從挑戰者變成戶政工具。
  • 天主教：1549年沙勿略傳入，九州形成吉利支丹社群；因被視為外來政治威脅而遭嚴禁，島原之亂（1637）後更嚴厲，促成鎖國。
  • 神道與國學：江戶後期本居宣長等推動國學，強調日本本土傳統，成為尊王思想的養分。

五、對外交流與鎖國　（第3章）

遣唐使與國風文化

630－894年遣唐使約19次。代表人物：阿倍仲麻呂、吉備真備、最澄（天台宗）、空海（真言宗）、圓仁。鑑真則自中國六次東渡、雙目失明仍抵日，建唐招提寺。
894年菅原道真建議廢止遣唐使 → 消化吸收 → 國風文化（假名、《源氏物語》、《枕草子》、大和繪、寢殿造）。

中世至近世的海上活動

  • 前期倭寇（14世紀）：九州、對馬的武士浪人劫掠朝鮮與中國沿海。
  • 勘合貿易（室町）：足利義滿受明冊封「日本國王」，納入朝貢體制。
  • 鐵炮傳入（1543，種子島）：改變戰爭型態，加速戰國統一。
  • 朱印船貿易（1604－1635）：遠赴安南、暹羅、呂宋，於會安、大城形成日本町。
  • 壬辰倭亂（1592、1597）：豐臣秀吉侵朝，明朝援朝；豐臣政權因此崩潰。

鎖國的真相

鎖國 ≠ 完全封閉

1635－39年鎖國令後，對外關係由幕府壟斷，保留四個窗口：
① 長崎——荷蘭商館設於出島（1641年由平戶遷入，西方唯一窗口，蘭學由此輸入：醫學《解體新書》、天文、砲術）；中國商船則泊長崎港內，1689年後集中於唐人屋敷
② 對馬藩——通朝鮮（朝鮮通信使1607－1811共12次）
③ 薩摩藩——控琉球（1609入侵後琉球「兩屬」）
④ 松前藩——接蝦夷（愛努）
關鍵認識：資訊與商品持續流入，蘭學累積了對西方的理解，這正是日本在黑船來航後能迅速轉型的重要基礎。

六、人群移動　（第4章）

  • 經濟性移民：1885年起官約移民赴夏威夷（紓解農村貧困、賺取僑匯）；其後進入北美西岸，遭遇排日（1907日美紳士協定、1924美國排亞移民法）；1908年「笠戶丸」抵巴西，形成今日最大海外日裔社群。
  • 國策性殖民移民：滿洲開拓團（1932－45），以武裝移民鞏固佔領區、充實兵源糧食，強制收購中朝農民土地；戰敗後造成大量死亡與「中國殘留孤兒」。
  • 另有赴臺灣、朝鮮、南洋的官吏、教師、商人與農業移民村。

務必分辨

夏威夷、巴西移民＝移民（為謀生而去，在他國法律下生活）
滿洲開拓團＝殖民（以國家武力為後盾，建立在剝奪當地居民的基礎上）

七、明治維新　（第5章）

從黑船到倒幕

1853年培里黑船來航 → 1854年《日美和親條約》（神奈川條約）、1858年《日美修好通商條約》（不平等）→ 幕府威信掃地 → 尊王攘夷 → 薩長與英法實際交手後轉為倒幕開國 → 1867大政奉還 → 1868王政復古。

改革內容

面向措施
政治版籍奉還、廢藩置縣（1871）；1889《大日本帝國憲法》（亞洲第一部成文憲法）、1890帝國議會
社會四民平等、秩祿處分與廢刀令（廢武士特權）、徵兵制（1873）
經濟殖產興業：地租改正、官營模範工廠、鐵路郵政銀行
教育學制（1872）義務教育；延攬外國顧問；岩倉使節團（1871－73）考察歐美
思想文明開化；福澤諭吉《勸學》、〈脫亞論〉（1885）

日本為何成功？

① 倒幕後權力高度集中，能貫徹全國一致的改革（對比中國督撫各自為政）。
② 改革全面到位——政治、社會、經濟、教育、軍事同步，不是只學器物。
③ 推動者就是被改革者——下級武士主導改革，親手廢除了自身階級的特權。
④ 鎖國期的蘭學積累，對西方並非一無所知。
⑤ 有時間——開國後約二十年的國際環境相對寬鬆。

八、擴張與戰爭　（第6章）

1874牡丹社事件 → 1876《江華島條約》 → 1879琉球處分 → 1894－95甲午戰爭（得臺澎、賠款二億兩、朝鮮「獨立」）→ 1904－05日俄戰爭（南滿權益、朝鮮支配權）→ 1905乙巳保護條約 → 1910日韓合併 → 1915二十一條 → 1931九一八事變、1932滿洲國、1933退出國聯 → 1937七七事變、南京大屠殺 → 1940「大東亞共榮圈」 → 1941偷襲珍珠港 → 1945投降。

成功的近代化與侵略，是同一個過程的兩面

日本因明治維新而富強，富強後便依循它所學習的十九世紀列強邏輯——取得殖民地、劃定勢力範圍、以武力維護權益。〈脫亞論〉的優越意識，則提供了對待亞洲鄰國的心理基礎。理解這一點，才能理解第5章與第6章為何必須連著讀。

九、戰後日本　（第6章）

  • 1947年《日本國憲法》：主權在民、象徵天皇制、第九條放棄戰爭與不保持戰力。
  • 經濟：韓戰特需景氣（1950）→ 高度經濟成長 → 1964東京奧運 → 1968年GNP躍居世界第二 → 1990年代泡沫破裂、「失落的十年」。
  • 外交：1951《舊金山和約》與《美日安保條約》；1965《日韓基本條約》；1972中日建交、沖繩歸還；1978《中日和平友好條約》。
  • 社會運動：1960年安保鬥爭，顯示冷戰體制下的內部張力。
  • 歷史認識：1993河野談話（慰安婦）、1995村山談話（殖民統治與侵略的「痛切反省與道歉」）；但教科書爭議、靖國神社參拜（合祀甲級戰犯）持續引發中韓抗議。
  • 領土爭議：釣魚臺／尖閣（與中、臺）、獨島／竹島（與韓）、北方四島（與俄）。

十、重點速記

日本線索一句話整理

  • 權威：神裔血統不可轉移 → 攝關 → 院政 → 幕府（公武二元約700年）→ 1868王政復古終結
  • 學唐：聖德太子 → 大化革新 → 白村江敗戰 → 大寶律令；引進律令官制佛教，獨不引進科舉
  • 對外：遣唐使 → 廢止後國風文化 → 倭寇／勘合 → 朱印船 → 鎖國但有四個窗口（蘭學）
  • 社會：士（武士）農工商世襲不可流動；寺請制度把佛教變成戶政工具
  • 近代化：黑船 → 倒幕 → 明治維新（政治社會經濟教育思想全面改革）→ 成功
  • 擴張：琉球 → 臺灣 → 朝鮮 → 滿洲 → 中國 → 東南亞 → 1945敗戰
  • 戰後：和平憲法第九條 → 特需景氣 → 1968世界第二 → 歷史認識與領土爭議未解
